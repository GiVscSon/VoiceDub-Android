# VoiceDub Android 0.6 — локальный многоязычный перевод

Основной режим: системный звук → Vosk → ML Kit → Android TTS. Теперь можно выбрать один из 20 языков перевода; голос TTS использует тот же язык. Есть 19 исходных моделей Vosk, включая русский. При одинаковых исходном и целевом языках выводится распознанный текст без вызова переводчика. MOSS на ПК пока доступен только для русской озвучки.

Два обновляемых варианта одного пакета (постоянный debug-сертификат, versionCode=8):
- **Core**: ручной выбор исходного языка, без дополнительного движка Sherpa.
- **Tiny**: дополнительно локальное определение языка речи Whisper tiny int8 через sherpa-onnx. Веса (~98 МиБ) скачиваются один раз отдельной кнопкой, проверяются SHA-256 и затем используются без отправки звука на сервер. Нужны установленные модели Vosk для ожидаемых языков. При недостатке речи, разногласии двух окон или отсутствии ASR-модели применяется выбранный вручную резервный язык.

Core и Tiny заменяют друг друга, сохраняя данные com.voicedub.app.preview; рабочая 0.4 остаётся отдельно. Не удаляйте приложение перед обновлением.

[Локальные модели, условия и проверки](LOCAL-MODELS.md). [Состояние дополнительного адаптера VOT](VOT-INTEGRATION-STATUS.md). Режимы независимы; отказ Яндекса не блокирует локальную цепочку.

## Сборка 0.6

JDK 17, Gradle 8.9, Android SDK 35. Для Tiny при сборке автоматически загружается hash-pinned runtime AAR; веса модели в основной APK не включаются.

```bash
npm ci --prefix vot-runtime
npm run build --prefix vot-runtime
node --test tests/*.test.cjs
python3 scripts/check_project.py
gradle :app:testCoreDebugUnitTest :app:assembleCoreDebug
gradle :app:testTinyDebugUnitTest :app:assembleTinyDebug
```

## Предыдущий этап: VOT preview

Новый режим Яндекса: автоматический выбор исходного языка на стороне сервиса, передача полной исходной дорожки по запросу, прогресс, отмена и ограниченный опрос. Это тестовая интеграция: реальный анонимный запрос создания сессии прошёл (HTTP 200), перевод вернул HTTP 402. Получение настоящей дорожки не подтверждено.

[Актуальное состояние и ограничения](VOT-INTEGRATION-STATUS.md). APK обновляет прежний preview-пакет com.voicedub.app.preview, рабочая 0.4 остаётся отдельно. Во встроенном браузере сначала откройте видео; язык Яндекса по умолчанию Auto. Если сервис запросит исходную дорожку, включите разрешение на её отправку и повторите запрос. Если прямая дорожка недоступна, можно выбрать полный исходный аудиофайл через системный диалог и повторить перевод. Лимит — 80 МиБ. Обычная пауза видео не останавливает подготовку; используйте «Отменить запрос Яндекса».

## Предыдущая версия 0.5.0-preview

Экспериментальный голосовой перевод видео для Android 10+, телефона и планшета. Рабочая локальная цепочка: разрешённый системный PCM → Vosk → ML Kit → русский Android TTS / субтитры. Пользователь подтвердил работу перевода в 0.4; новые функции 0.5 проверены отдельно согласно [отчёту](RELEASE-0.5.0.md).

Приложение 0.5 называется «VoiceDub 0.5 · тест» и устанавливается рядом с 0.4 (applicationId `com.voicedub.app.preview`). Рабочую 0.4 удалять не нужно. В новой установке модель распознавания нужно скачать отдельно. Для следующих обновлений preview используется постоянный публичный debug-сертификат, не предназначенный для production.

## Что добавлено

- Опциональная озвучка с особенностями исходного голоса через MOSS-TTS-Nano на вашем ПК. Android собирает 3–8 секунд образца из разрешённого источника, отправляет его и переведённый текст только на выбранный сервер и проигрывает WAV. Это не локальный синтез на телефоне.
- [Сервер и запуск на Windows/Linux](companion/README-RU.md). API-ключ не нужен. Включение явное; при ошибке сервера приложение сообщает о переходе на обычный русский TTS.
- Изолированный экран Яндекс OAuth с PKCE, как в присланном VOT 1.12.3. Пароль вводится на странице Яндекса; токен хранится в памяти приложения, не передаётся видеосайту и серверу MOSS.
- Во встроенном браузере — экспериментальная кнопка запроса VOT для YouTube/Vimeo. Используется @vot.js/core 3.2.0 в отдельном локальном WebView с ограниченным доступом к HTTPS-методам сессии, перевода и передачи исходного аудио Яндекса. Готовая дорожка подключается к существующей синхронизации плеера и требует нажатия кнопки внутри страницы.
- Сброс образца, распознавания, ожидающей речи и запросов при паузе/перемотке/смене видео. Русские фразы больше не прерываются каждой новой фразой.

## Ограничения

MOSS сейчас рассчитан на одного говорящего: нет разделения музыки, распознавания смены диктора и точной губной синхронизации. На CI CPU синтез медленнее воспроизведения; большие задержки приводят к отбрасыванию старых ожидающих фраз. Похожесть голоса не измерена. Живой вход с аккаунтом Яндекса и получение аудиодорожки VOT не подтверждены. Прямой пробный запрос из среды разработки завершился ошибкой; это не доказывает недоступность сервиса на устройстве пользователя.

Захват Android зависит от политики источника. DRM, запреты приложений и системные ограничения не обходятся. Для внешнего браузера субтитрам нужно разрешение на плавающее окно; встроенный браузер имеет собственный слой субтитров.

## Сборка и проверки

JDK 17, Gradle 8.9, Android SDK 35:

```bash
python3 scripts/check_project.py
npm ci --prefix vot-runtime
npm run build --prefix vot-runtime
node --test tests/*.test.cjs
python3 -m unittest discover -s tests -p 'test_*.py' -v
gradle :app:testDebugUnitTest :app:assembleDebug
```

GitHub Actions: `Build VoiceDub Android APK` собирает и проверяет подписанный APK. `Voice model and Android integration` выполняет настоящие HTTP-запросы к модели и затем тесты на эмуляторах Pixel 2 и Pixel C, Android 15. Границы этих проверок и ссылки на запуски — в [RELEASE-0.5.0.md](RELEASE-0.5.0.md).
