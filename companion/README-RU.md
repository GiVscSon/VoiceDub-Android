# Сервер исходного голоса для VoiceDub 0.5

Экспериментальный режим: Android распознаёт и переводит текст, а MOSS на вашем ПК создаёт русскую речь по короткому образцу исходного голоса. Интернет нужен для первоначальной установки библиотек и загрузки моделей. GPU и API-ключ не нужны. Полностью автономный синтез на телефоне не реализован.

## Windows

Установите Python 3.11 и распакуйте этот комплект в отдельную папку. В PowerShell из этой папки:

```powershell
powershell -ExecutionPolicy Bypass -File .\start-voice-server.ps1 -BindAddress 0.0.0.0
```

Параметр ExecutionPolicy действует только для этого запуска. Первый запуск устанавливает CPU-зависимости и скачивает модель; дождитесь сообщения `VoiceDub MOSS server ready`. Разрешите входящее соединение Python только в вашей частной домашней сети. Не открывайте порт 8765 на роутере. Сервер без параметра BindAddress доступен только самому ПК.

Посмотрите локальный IPv4 ПК командой `ipconfig`. На телефоне/планшете в общей Wi-Fi сети введите `http://IP_ПК:8765`, нажмите «Проверить сервер голоса», затем включите «Сохранять особенности исходного голоса» и запустите обычный перевод. Передача образца начинается только с этим флажком. Для источника лучше одна чистая речь без музыки. В начале до накопления 3 секунд используется обычный TTS.

Остановить сервер — Ctrl+C. Образцы не образуют библиотеку голосов: Android держит их в памяти сеанса, сервер удаляет временный WAV после запроса. Музыка и несколько говорящих пока не разделяются. При недоступности/занятости сервера приложение явно сообщает о переходе на обычный русский голос.

## Linux / ручной запуск

В окружении с зависимостями закреплённого MOSS-TTS-Nano:

```bash
python voice_server.py --moss-dir /path/to/MOSS-TTS-Nano --host 0.0.0.0 --port 8765
```

Код MOSS: https://github.com/OpenMOSS/MOSS-TTS-Nano, commit `8b7bcc9341b3b4ef3a3a58ba1338a7d85ff133eb`. Скорость и похожесть голоса зависят от образца и ПК; губная синхронизация и разделение нескольких дикторов не реализованы.
