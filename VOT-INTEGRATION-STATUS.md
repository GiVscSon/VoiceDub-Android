# VOT — интеграция 0.6 preview (29 октября 2026)

База: feature/multilingual-catalog e172a4f, включая 18 исходных языков локального перевода. Новая ветка feature/vot-source-audio.

## Реализовано

- Локальный изолированный @vot.js/core 3.2.0 runtime, сборка из vot-runtime/engine.js воспроизводится и проверяется CI. Native bridge отсутствует на видеостранице.
- Яндекс VOT по умолчанию получает requestLang=auto. Это режим определения языка на стороне Яндекса, а не локальная speech LID модель. Ручной выбор сохраняется как опция. Vosk/ML Kit для VOT не требуются.
- Полная исходная аудиодорожка передаётся только после отдельного разрешения пользователя и ответа AUDIO_REQUESTED=6. Статусы PART_CONTENT=5 и SESSION_REQUIRED=7 обрабатываются отдельно.
- Доступный незашифрованный audio URL берётся из публичных данных текущего YouTube-плеера с проверкой videoId. Нативная загрузка разрешена только с HTTPS CDN googlevideo.com/vimeocdn.com, без cookies/OAuth, с проверкой каждого перенаправления. Нет расшифровки signatureCipher, poToken, обхода DRM или запретов источника. Для недоступного источника есть системный выбор исходного аудиофайла; пользователь должен выбрать полную дорожку именно текущего видео.
- Дорожка до 80 МиБ размещается в приватном временном файле; поддерживаются сигнатуры распространённых аудиоконтейнеров. В памяти находится одна часть, а не весь ролик. Передача PUT /video-translation/audio использует protobuf, подпись сессии, постоянный fileId, последовательные chunkId, полное количество частей и размер 5295308 байт кроме последней части. Пустые фиктивные запросы не отправляются.
- OAuth хранится в памяти и добавляется только нативно к запросу перевода. Он не передаётся видеостранице, CDN, серверу MOSS или в сообщения диагностики.
- Отмена закрывает соединение и блокирует устаревшие ответы/дальнейшие части. Срабатывает при смене плеера, навигации, уходе из Activity и явной отмене. Обычная пауза видео оставляет подготовку полной дорожки активной; чтобы прекратить передачу, есть кнопка отмены. Опрос ограничен 20 минутами/80 запросами, учитывает remainingTime. Частичная готовая дорожка не считается окончательным завершением.
- Элементы управления прокручиваются в панели, оставляя место видео на телефоне и планшете. Preview обновляет пакет com.voicedub.app.preview, versionCode=7, постоянный debug-сертификат прежний.

## Проверки

25 Node-тестов прошли локально: фактическое protobuf-кодирование/декодирование полного цикла с подставными сетевыми ответами, части >5 МБ и контрольная сумма восстановленного файла, первая/последующая попытки, язык auto, статусы 5/6/7, отмена и отказ от пустого источника. 5 Python-тестов сервера голоса прошли. Это не подтверждение ответа живого Яндекса.

Kotlin-тесты и Android build запускаются в CI. Новый workflow VOT Android transport and layout проверяет передачу большого файла через реальный Android WebView/JNI bridge с подставным транспортом и размер области видео на Pixel 2/Pixel C. Результат конкретного запуска смотреть в PR.

Реальный анонимный probe scripts/check_vot_live.mjs: создание сессии вернуло HTTP 200, запрос перевода публичного демонстрационного YouTube-видео — HTTP 402. Поэтому реальная выдача переведённой дорожки и её приём сервисом после загрузки исходного файла не подтверждены. Причина HTTP 402 не установлена; не называть это требованием оплаты без доказательства. Вход с аккаунтом проверяется на устройстве пользователя.

Остались: реальные YouTube-плееры могут не публиковать пригодный прямой URL; автоматической загрузки в таких случаях нет. Сохранение голоса MOSS остаётся отдельным режимом через ПК. Локальное автоматическое определение языка по PCM пока не реализовано. Полная проверка VOT на физическом устройстве, качество перевода и длительная синхронизация ещё нужны.
