# Локальные модели VoiceDub 0.6

## Режимы

- Core: локальные ASR Vosk, перевод ML Kit после первоначальной загрузки нужных моделей и установленный голос Android TTS. Наличие нужного голоса зависит от TTS-движка устройства; при его отсутствии выдаётся диагностика и остаются субтитры. Сам движок TTS может использовать сеть в зависимости от установленного голоса.
- Tiny: та же цепочка плюс optional Whisper tiny int8 / sherpa-onnx 2.0.1 для определения исходного языка **по PCM до ASR**. Не чат-бот, не генератор голоса и не модель клонирования голоса.

## Модель и границы

Веса: encoder 12937772 байта + decoder 89855401 байт = 102793173 байта (около 98 МиБ). Revision Hugging Face csukuangfj/sherpa-onnx-whisper-tiny: 65176e2deb88badc814a94058666cadccc29b61c. Хеши/размеры закреплены в TinyLanguageAssets.kt. Загрузка атомарная, неполные/неверные файлы не активируются. В APK Tiny включён runtime; веса скачиваются отдельно. Core не содержит этот runtime. Поддерживаются ABI опубликованного AAR (arm64-v8a, armeabi-v7a, x86, x86_64).

Автоопределение выключено по умолчанию. После установки Tiny нажмите «Скачать Whisper tiny», скачайте Vosk-модели ожидаемых исходных языков, укажите резервный исходный и целевой языки и включите локальное автоопределение. Выбранные веса затем используются без сервера. Собирается до 6 секунд PCM с достаточным уровнем сигнала; ожидание ограничено примерно 20 секундами входного звука. Фильтр по энергии не является нейросетевым VAD. Два отдельных окна должны дать одинаковый код языка; API Whisper LID не выдаёт confidence, поэтому проценты уверенности не показываются.

Результат должен иметь установленную Vosk-модель. При недостатке речи, ошибке движка, разногласии окон, неподдерживаемом языке или отсутствии модели применяется явно выбранный резерв. Он записывается в диагностику. Модель LID освобождается до загрузки Vosk, чтобы уменьшить одновременное потребление памяти. Для стадии подготовки увеличен буфер AudioRecord до 20 секунд; собранное вступление передаётся распознавателю. На очень медленных устройствах возможны задержка и пропуски при переполнении буфера.

Определение выполняется один раз при запуске захвата. Для ролика на другом языке перезапустите захват. Несколько одновременно говорящих, музыка, смешение языков и короткие реплики могут привести к ошибкам. Качество на реальных устройствах пользователя ещё не измерено. Сохранение исходного голоса MOSS остаётся отдельной экспериментальной функцией через ПК и только для русского целевого языка.

## Проверки

Реальная модель запущена на CPU среды разработки: немецкий и арабский примеры upstream определены правильно в обоих окнах. Загрузка около 0.68 с, две классификации каждого примера суммарно около 0.3 с. Это серверный CPU, а не оценка телефона.

Android CI проверяет Core/Tiny, единый язык переводчика/TTS, сохранение целевого языка при пересоздании экрана, ограничение MOSS русским, отсутствие скачивания переводчика для одинаковых языков и реальные ONNX-инференсы немецкого/арабского на Pixel 2/Pixel C. Результаты конкретного SHA смотреть в PR: не считать запланированную проверку пройденной до её завершения. Живой системный захват на физических устройствах в этих тестах не воспроизводится.

Модели и runtime берутся из официальных опубликованных проектов sherpa-onnx / Whisper. Лицензии включены в third-party/ и APK Tiny. Публичные тестовые аудио загружаются только в тестовый APK, пользовательские записи не используются.
