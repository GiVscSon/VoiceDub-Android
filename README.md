# VoiceDub Android 0.6.1

Перевод звука видео на Android 10+, телефон и планшет: системный звук → Vosk → ML Kit → Android TTS / субтитры. Доступны 19 исходных и 20 целевых языков.

Основная устанавливаемая версия — **VoiceDub-0.6.1.apk**, универсальная сборка с возможностью включить локальное определение языка Tiny. [Скачать релиз](https://github.com/GiVscSon/VoiceDub-Android/releases/tag/v0.6.1). [Описание версии и ограничения](RELEASE-0.6.1.md).

## Установка

Установите APK поверх прежних preview / Core / Tiny без удаления приложения: сохранены пакет com.voicedub.app.preview и сертификат, versionCode=9. Рабочая 0.4 имеет отдельный пакет.

Выберите исходный и целевой языки, скачайте исходную модель Vosk и начните перевод. ML Kit загружает необходимые модели при первом использовании. Голос Android должен поддерживать целевой язык; при его отсутствии остаются субтитры.

Для локального автоопределения скачайте Whisper tiny int8 (~98 МиБ) и Vosk-модели ожидаемых языков, включите переключатель. Определение выполняется один раз в начале захвата; при недостатке речи, несовпадении окон или отсутствии нужной модели используется выбранный резервный язык. Причина записывается в «Последнюю диагностику». [Условия локальной модели](LOCAL-MODELS.md).

Разрешение на плавающее окно нужно только для субтитров поверх других приложений. Для встроенного браузера и одной озвучки оно не требуется. Android может запрещать захват некоторых источников.

## Дополнительные режимы

- [MOSS на собственном ПК](companion/README-RU.md): экспериментальная русская озвучка с образцом исходного голоса. Включается явно; требует сервера, на который отправляются текст и образец. Не является синтезом на телефоне.
- [Яндекс VOT](VOT-INTEGRATION-STATUS.md): отдельный экспериментальный адаптер. Последний анонимный запрос перевода вернул HTTP 402, получение настоящей дорожки не подтверждено.
- Yandex Cloud Translate требует собственных API-ключа и Folder ID. Вход VOT не предоставляет эти реквизиты.

Локальный перевод не зависит от этих режимов. Офлайн-работа озвучки зависит от установленного TTS-движка и голосов.

## Сборка и проверки

JDK 17, Gradle 8.9, Android SDK 35. Дополнительный runtime Tiny загружается при сборке с проверкой закреплённого SHA-256; веса нейросети скачиваются отдельно в приложении.

```bash
python3 scripts/check_project.py
npm ci --prefix vot-runtime
npm run build --prefix vot-runtime
node --test tests/*.test.cjs
python3 -m unittest discover -s tests -p 'test_*.py' -v
gradle :app:testCoreDebugUnitTest :app:testTinyDebugUnitTest :app:testTinyReleaseUnitTest
gradle :app:assembleTinyDebug :app:assembleTinyRelease
```

Основной APK: app/build/outputs/apk/tiny/release/app-tiny-release.apk.
Лёгкий вариант для разработки: :app:assembleCoreDebug без runtime определения языка.

Release не debuggable; для обновления существующих установок APK подписан прежним публичным сертификатом. Это sideload-канал, не production-подпись Google Play.

Workflow сборки проверяет APK и публикует релиз после успешной матрицы Pixel 2 / Pixel C с настоящими ONNX-весами. Проверка MOSS выполняется отдельно через HTTP и класс VoiceFlowTest; Tiny-проверки запускаются только в соответствующей матрице. Полный системный захват на физическом устройстве в CI не воспроизводится.
