# VoiceDub 0.6.1

Итоговая устанавливаемая сборка текущего этапа для Android 10+, телефона и планшета. Основной файл — VoiceDub-0.6.1.apk, универсальный вариант с поддержкой Tiny. Локальный перевод работает независимо от Яндекса и сервера на ПК.

## Возможности

- 19 исходных языков Vosk и 20 целевых языков перевода. Android TTS использует выбранный целевой язык; доступны субтитры, озвучка или оба режима.
- Локальное определение исходного языка по звуку через Whisper tiny int8 / sherpa-onnx. Дополнительные веса около 98 МиБ скачиваются отдельно с проверкой SHA-256.
- Ручной выбор исходного языка остаётся резервом. Определение выполняется один раз при запуске захвата, требует согласия двух окон и установленной Vosk-модели результата.
- Во встроенном браузере — обнаружение видеоплеера и субтитры; для Chrome/Opera доступен системный захват разрешённого источником аудио.

## Установка и первый запуск

1. Установите APK поверх VoiceDub preview / Core / Tiny, не удаляя приложение. Пакет com.voicedub.app.preview и прежний сертификат сохранены; versionCode повышен до 9. Версия 0.4 устанавливается отдельно.
2. Выберите исходный язык, скачайте его модель Vosk, выберите целевой язык. Модели перевода ML Kit первоначально скачиваются автоматически. Для озвучки нужен голос Android соответствующего языка.
3. Для автоопределения скачайте Whisper tiny и Vosk-модели ожидаемых языков, включите соответствующий переключатель. При другом языке перезапустите захват. Результат либо причина резервного выбора доступны в «Последней диагностике».
4. Начните перевод системного аудио и подтвердите запрос Android, затем включите видео.

## Границы итоговой версии

Речь для локального определения не отправляется на сервер. Голос TTS может использовать сеть в зависимости от установленного движка и голосового пакета. Модель языка не клонирует голос; переключение языка внутри ролика и разделение говорящих не реализованы. Музыка, шум и короткие реплики могут приводить к резервному выбору.

Дополнительные режимы остаются экспериментальными: MOSS на ПК — только русский, без подтверждённой похожести голоса; Яндекс VOT — в последнем анонимном испытании перевод ответил HTTP 402, выдача реальной дорожки не подтверждена. Они не требуются для локального режима. Android может запрещать захват звука отдельных приложений и защищённого контента.

Это сборка для установки APK напрямую. Отладка в release отключена. Для совместимости обновлений используется прежний публичный сертификат sideload-пакета; он не является production-идентичностью для Google Play.

## Проверки перед публикацией

CI собирает APK release, проверяет подпись, совпадение сертификата с debug/прежней preview, пакет, версию, отсутствие debuggable и наличие четырёх ABI. Публикация на GitHub выполняется только после успешной сборки, Kotlin/JS/Python проверок и матрицы настоящей Tiny-модели на Pixel 2 и Pixel C (эмуляторы Android 15). Хеш APK и идентификатор коммита включаются в SHA256SUMS.txt и validation.json.

Полный цикл новой функции автоопределения на физическом устройстве в этих тестах не воспроизводится. Работа перевода на устройствах ранее подтверждена пользователем; это не доказывает качество нового автоопределения во всех условиях.
